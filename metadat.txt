Document-level fault isolation means:

If one source document fails, log the failure and continue processing the next document.

Example:

Document A → success
Document B → failure → ERROR log → skip B
Document C → success
Document D → success

The final pipeline must continue with A, C and D.

Do NOT allow B's exception to terminate the entire batch.

Do NOT silently ignore the failure.

Do NOT fabricate a replacement Document.

Do NOT fabricate chunks for a failed Document.

IMPORTANT:

- process the source file independently
- catch its failure
- log the failure using the existing/frozen ERROR logging approach
- skip that source file
- continue with the next source file
